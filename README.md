## Overview

The project answers two simple business questions on a synthetic dataset:

1. **Which region generates the most revenue?**
2. **How does revenue change month by month?**

It demonstrates a clean documentation workflow: a professional `README.md`,
a commented R script, and an R Markdown file that explains the script's
purpose, inputs and outputs.

## Dataset

All data are **synthetic** and generated by `R/generate_synthetic_data.R`.
No real or personal data are used.

| Column | Type | Description |
|--------|------|-------------|
| `order_id` | character | Unique order ID (`ORD-0001` …) |
| `order_date` | date | Order date in 2025 |
| `region` | character | North, South, East, West |
| `product` | character | Laptop, Monitor, Keyboard, Headset |
| `units` | integer | Units sold (1–10), ~3 % missing on purpose |
| `unit_price` | numeric | Price per unit (USD) |

## Installation

**Requirements:** R ≥ 4.1 and RStudio or Posit Cloud.

1. Clone the repository:

   ```bash
   git clone https://github.com/agafonovapoligon-hue/markdown-buddy-viktoriiaagafonova.git
   cd markdown-buddy-viktoriiaagafonova
   ```

2. Install the R packages:

   ```r
   install.packages(c("readr", "dplyr", "ggplot2", "rmarkdown", "knitr"))
   ```

## Usage

Run the scripts from the project root, in this order:

```r
source("R/generate_synthetic_data.R")  # 1. create data/synthetic_sales.csv
source("R/sales_summary.R")            # 2. build summaries and chart
rmarkdown::render("sales_summary.Rmd") # 3. build the HTML documentation
```

## Example Code

The core of the analysis groups cleaned orders by region:

```r
library(dplyr)

region_summary <- sales |>
  group_by(region) |>
  summarise(
    orders          = n(),
    total_revenue   = sum(revenue),
    avg_order_value = mean(revenue),
    .groups = "drop"
  ) |>
  arrange(desc(total_revenue))
```
